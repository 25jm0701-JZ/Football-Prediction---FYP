# 当前研究主线：66→36→泛化检验→LR 指导泊松

## 研究问题

仅使用赛前历史信息，能否得到有用的比赛概率？在同样的 LR 设置下，能否减少冗余特征而保持或改善概率质量？再将该赛果概率与泊松比分结构结合，是否比纯泊松更好？

LR 适合本研究的理由是直接给出三类概率、便于控制特征数量、解释和复现。它不是被证明普遍最强的算法；当前主要证据是相同 LR 训练条件下的受控对照。

## 1. 建立干净的 66 特征基线

输入来自 E0–E3、2019/20–2025/26 的 28 份 CSV，共 13,988 场。66 列包括双方的 5/10 场历史状态与射门效率、5 个交锋特征和联赛等级。历史射门可以作为滞后特征，当场射门不能用于赛前预测。球队历史按球队名称串联，保留升降级前的记录。

赔率仅作外部基准。禁止将当场统计、半场信息、FootyStats 当前赛季汇总引入此主线。训练集均值插补只在训练数据拟合。

## 2. 从 66 列重新筛选，得到 36 列

在 2022/23 计算置换重要性，2023/24–2024/25 验证 76 个候选组合，以 Log Loss 为主选择指标。重新运行没有读取旧重要性或旧列集，也没有预设必须得到 36 列。

选出的 `window_10_only` 含双方近 10 场历史统计共 30 列、交锋 5 列、联赛等级 1 列。此后固定该列集。原版和简化版都不标准化，C=1，采用相同插补和训练方法，控制比较中只改变列集。

完整选择证据在[开发结果](../experiments/feature_rebuild_poisson_20261015/development/frozen_selections.json)，逐列信息在[特征保留清单](../experiments/feature_rebuild_poisson_20261015/results/feature_retention.csv)。

## 3. 泛化检验：相同比赛、相同训练边界

2019/20 的 1,772 场只作初始历史；2020/21–2025/26 各评价 2,036 场，共 12,216 场。每季拟合此前全部赛季，测试季内模型参数冻结。滚动历史可以从更早日期更新，同一天比赛彼此不可见。

| 比较 | 原版 66 | 简化 36 |
|---|---:|---:|
| 准确率 | 45.6287% | 46.0707% |
| Log Loss | 1.056095 | 1.053133 |
| Macro F1 | 0.352288 | 0.349281 |
| 平局 F1 | 0.042068 | 0.026586 |

少 30 个输入，净多正确 54 场。六季与四联赛的 Log Loss 汇总均改善。日期聚类区间支持 Log Loss 改善，准确率区间包含零；平局识别仍弱。

“泛化检验”在这里指固定子集在不同历史季和联赛上的比较。由于列集由较晚历史筛选，六季整体是回顾性对照；不能声称早期季相对特征选择完全未见。2025/26 位于本次选择时序之后，但也已被先前研究查看。未来有效性仍需要冻结规则后的新比赛。

## 4. LR 指导泊松

泊松基线保留原攻防参数估计，平滑为 0.05；依据赛前预测的两个进球均值生成比分网格，舍弃质量不超过 1e-12。三种比分模型使用相同支持与评价定义。

设 `P(i,j)` 为原泊松比分概率，`S(c)` 为赛果区域 c 的泊松总概率，`q(c)` 为 LR 概率，则 `F(i,j)=q(c)P(i,j)/S(c)`。这样三大区域分别匹配 LR，区域内部比分比例保持不变。

比较纯泊松、66 特征 LR＋泊松、36 特征 LR＋泊松，比分 NLL 分别为 3.005417、2.967725、2.964762；精确比分命中率分别为 11.8533%、12.1807%、12.0498%。简化融合相对纯泊松多命中 24 场，相对原版融合少 16 场，两个差异区间均包含零。相对纯泊松的进球 MAE 改善，但相对原版融合略差。

融合赛果指标等于对应 LR 指标，是公式保证。比分 NLL 的改善与赛果 Log Loss 改善相同，因此概率质量改善不代表又学到了更细的区域内部比分规律。不能宣称比分各指标全面提升、公式首创、已优于市场或带来投注盈利。

## 论文结构

绪论提出赛前概率预测问题；文献综述解释评分、分类与泊松路线；方法介绍 66 特征、一次性筛选、固定 36 特征和分区融合；实验按原版 LR、简化 LR、纯泊松和两种融合展开；讨论区分概率评分、点预测、回顾性限制与未来验证。

研究贡献定位为严格赛前信息约束下的受控特征简化、分类概率与比分结构整合，以及跨季、跨联赛的可复核证据。最新完整数值见[实验报告](../experiments/feature_rebuild_poisson_20261015/results/report_CN.md)。
