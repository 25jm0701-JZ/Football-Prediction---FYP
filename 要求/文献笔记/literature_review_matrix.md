# 联赛预测文献与方法对应矩阵

当前本地文献PDF为5份，均服务于联赛赛前预测、特征工程或比分概率评价。详细作者、来源与局限见[文献综述](../../docs/literature_review_CN.md)。

| 文献 | 与本项目的关系 | 采用的研究步骤 |
|---|---|---|
| Buchdahl 2003 | 近期净胜球与球队状态评分 | 历史窗口、主客状态表达、概率评价 |
| Atta Mills等2024 | 多模型比较与工程特征，区分半场和赛前信息 | 模型参照、输入贡献、排除开赛前不可得变量 |
| Luiz等2024 | 神经网络、历史窗口、相对能力与置换重要性 | 窗口比较、重要性分析、候选组合验证 |
| Loukas等2024 | 历史攻防强度与独立泊松比分分布 | 共同比分基线与赛果区域汇总 |
| Reade等2020 | 双变量泊松、滚动历史、比分与市场评价 | 时间顺序评价、概率与点预测分开报告 |

本项目从66个干净赛前特征中筛选出固定36个特征，进行跨赛季、跨联赛检验，再将LR赛果概率用于泊松比分区域重加权。文献的样本、输入时点和指标不同，不按论文标题准确率直接排名。

分区更新的相关理论、联赛混合模型与工程先例另见文献综述第7节。当前主要贡献是受控的特征简化与概率整合验证，没有证明算法普遍最优或盈利。
