# Rating Systems for Fixed Odds Football Match Prediction - 方法论笔记

## 基本信息

- 原文件: `要求/文献/ratings.pdf`
- 标题: Rating Systems for Fixed Odds Football Match Prediction
- 作者: Joe Buchdahl
- 来源: Football-Data, 2003
- 主题: 固定赔率足球赛果预测中的 rating system 与 value betting

## 研究目标

本文的目标是说明如何用一个简单的球队评分系统，把历史表现转化为未来比赛的赛果概率，再把概率转化为公允赔率，并与博彩公司赔率比较，以识别可能的 value bets。

文章不是建立复杂机器学习模型，而是演示一个透明、可复现的统计预测流程:

1. 用近期比赛表现计算球队强弱评分。
2. 用主客队评分差得到单场比赛评分。
3. 用历史比赛数据把评分映射为主胜、平局、客胜概率。
4. 用拟合曲线平滑概率估计。
5. 把概率转化为 fair odds。
6. 与 bookmaker odds 比较，判断是否存在 value bet。
7. 用历史赛季进行投注回测。

## 核心评分方法

文章示范的是 goals superiority rating system，即基于近期净胜球的强弱评分。

球队评分定义为:

```text
球队评分 = 最近6场进球数 - 最近6场失球数
```

单场比赛评分定义为:

```text
比赛评分 = 主队评分 - 客队评分
```

例子:

- Tottenham 最近 6 场进 6 球、失 9 球，评分为 -3。
- Leeds 最近 6 场进 8 球、失 11 球，评分为 -3。
- 因此 Tottenham vs Leeds 的比赛评分为 0。

文章的基本假设是: 最近一段时间进球更多、失球更少的球队，在下一场比赛中更可能表现更好。

## 历史数据与概率估计

作者使用 1993/94 到 2000/01 赛季英格兰 Premier League 以及 Divisions 1, 2, 3 的比赛结果数据。

- 总比赛数: 16,272 场
- 可用于最近 6 场评分计算的比赛: 14,002 场
- 排除原因: 每个赛季初期球队尚未踢满 6 场，无法计算近期状态评分。

作者对每个比赛评分值统计历史结果分布:

- 主胜次数与比例
- 平局次数与比例
- 客胜次数与比例

例如，比赛评分为 0 的历史比赛中:

- 主胜约 45.6%
- 平局约 28.5%
- 客胜约 25.9%

这说明评分为 0 时，模型给出的概率接近英格兰联赛整体长期分布。

## 拟合模型

直接使用每个评分对应的历史频率会有噪声，尤其是在极端评分处，因为样本很少。因此作者用 Excel 对评分和赛果概率做拟合。

设:

```text
x = 比赛评分
y = 某一赛果发生的概率百分比
```

拟合结果如下:

```text
主胜概率: y = 1.56x + 46.47, R^2 = 0.8623
客胜概率: y = 0.03x^2 - 1.27x + 23.65, R^2 = 0.7533
平局概率: y = -0.03x^2 - 0.29x + 29.48, R^2 = 0.3918
```

解释:

- 主胜概率与比赛评分的线性关系较强，拟合效果最好。
- 客胜概率也有较强关系，但用二次曲线拟合。
- 平局最难预测，R^2 很低，说明评分对平局概率解释力较弱。

## 公允赔率计算

模型先预测赛果概率，再将概率转化为公允赔率:

```text
公允赔率 = 100 / 赛果概率百分比
```

例如评分为 0 时:

```text
主胜概率 = 46.47%
主胜公允赔率 = 100 / 46.47 = 2.15
```

Tottenham vs Leeds 的例子中，模型给出:

- 主胜 fair odds: 2.15
- 平局 fair odds: 3.39
- 客胜 fair odds: 4.23

## Value betting 逻辑

如果博彩公司给出的赔率高于模型计算出的公允赔率，则说明博彩公司低估了该结果发生概率，投注者可能获得正期望。

判断规则:

```text
bookmaker odds > model fair odds => potential value bet
```

例子:

- 模型认为 Tottenham 主胜公允赔率为 2.15。
- Interwetten 给出的 Tottenham 主胜赔率为 2.20。
- 因为 2.20 > 2.15，所以这是潜在 value bet。

文章强调，预测最可能结果不等于盈利。长期盈利依赖的是概率估计是否比市场更准确，以及是否能持续找到赔率高于公允赔率的下注机会。

## 回测设计

作者用 2001/02 赛季英格兰联赛比赛进行模拟投注。

规则:

- 使用 goals supremacy rating system 识别主胜 value bets。
- 每次发现 value bet 时下注 1 unit。
- 比较不同评分范围下的收益。
- 使用 6 家博彩公司中的 best odds。
- 同时与盲买所有主胜进行比较。

结果:

| 策略范围 | 下注数 | Profit | Yield |
|---|---:|---:|---:|
| 所有评分 | 526 | +11.07 | +2.10% |
| -10 到 +10 | 459 | +16.32 | +3.56% |
| -5 到 +5 | 330 | +17.65 | +5.35% |
| -2 到 +2 | 171 | +17.32 | +10.13% |
| 盲买所有主胜 | 1746 | -65.20 | -3.73% |

一个重要发现是: 越接近评分 0 的区间，收益率越高。原因是中间评分样本更多，概率拟合更可靠；极端评分样本少，估计更不稳定。

## 方法论优点

- 结构清楚，容易复现。
- 只需要比赛结果和近期进失球数据。
- 能把球队状态转化为概率，而不是只输出胜负判断。
- 与赔率比较后可以自然进入 value betting 框架。
- 回测部分提供了实际投注收益评价，而不是只看预测准确率。

## 方法论局限

- 只使用最近 6 场净胜球，变量非常少。
- 没有显式控制对手强弱，虽然文中提到 Power Ratings 可解决这一点。
- 平局预测能力弱。
- 极端评分样本少，概率估计不稳定。
- 拟合方式较简单，依赖 Excel 趋势线。
- 回测主要展示主胜 value bets，没有系统展示平局和客胜策略结果。
- 未考虑赔率变化、交易成本、投注限额、模型过拟合等实际问题。

## 对 FYP 的启发

这篇文章适合作为基础型 rating model 的方法来源，尤其适合放在文献综述中说明:

- 传统足球预测可以从简单 rating system 起步。
- 近期净胜球差是一种可解释的球队状态指标。
- 赛果预测应输出概率分布，而不是只输出类别标签。
- 模型评价可以结合 bookmaker odds 和 ROI，而不仅是 accuracy。
- 需要注意 draw outcome 和 extreme ratings 的预测困难。

如果后续项目要预测世界杯或联赛结果，可以把这篇的方法作为 baseline:

```text
recent goal difference rating -> match rating -> historical probability mapping -> fair odds / predicted probabilities
```

然后再与 Elo、FIFA ranking、Poisson model、机器学习模型进行比较。
