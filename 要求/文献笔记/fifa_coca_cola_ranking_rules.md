# Revision of the FIFA/Coca-Cola World Ranking - 规则笔记

## 基本信息

- 原文件: `要求/文献/积分计分规则.pdf`
- 标题: Revision of the FIFA / Coca-Cola World Ranking
- 作者/机构: FIFA
- 主题: 新版 FIFA/Coca-Cola World Ranking 的 SUM/Elo 式积分公式

## 文档作用

这不是研究论文，而是 FIFA 官方排名算法说明。它适合作为 FYP 中“FIFA Ranking 特征如何形成”的方法来源，也可用于解释为什么 FIFA Ranking 可被视为一种动态强度评分。

## 核心公式

新版 FIFA Ranking 使用类似 Elo 的加减分机制:

```text
P = Pbefore + I * (W - We)
```

其中:

- `P`: 赛后积分
- `Pbefore`: 赛前积分
- `I`: 比赛重要性权重
- `W`: 实际比赛结果
- `We`: 预期比赛结果

## 比赛结果 W

```text
胜 = 1
平 = 0.5
负 = 0
```

点球大战特殊处理:

```text
点球大战胜者 W = 0.75
点球大战负者 W = 0.5
```

## 预期结果 We

```text
We = 1 / (10^(-dr/600) + 1)
```

其中:

```text
dr = Team A赛前积分 - Team B赛前积分
```

解释:

- 如果球队 A 积分高于球队 B，则 `dr` 为正，A 的 `We` 更高。
- 如果高排名球队获胜，获得积分较少，因为这是预期结果。
- 如果低排名球队爆冷获胜，获得积分较多。

## 比赛重要性 I

文档列出不同比赛类型的权重:

| 比赛类型 | I |
|---|---:|
| 国际比赛日窗口外友谊赛 | 5 |
| 国际比赛日窗口内友谊赛 | 10 |
| Nations League 小组赛 | 15 |
| Nations League 附加赛和决赛 | 25 |
| 洲际赛事和世界杯预选赛 | 25 |
| 洲际杯赛到四分之一决赛前 | 35 |
| 洲际杯赛四分之一决赛及以后、Confederations Cup | 40 |
| 世界杯正赛到四分之一决赛前 | 50 |
| 世界杯四分之一决赛及以后 | 60 |

## 淘汰赛保护规则

在决赛阶段淘汰赛中，如果球队根据公式会扣分，则不扣分:

```text
如果 (W - We) < 0，则 P = Pbefore
```

这个规则用于保护已经晋级淘汰赛的球队，避免它们因参加高水平淘汰赛而排名受损。

## 初始转换

新版 SUM 算法从旧 FIFA Ranking 平滑过渡:

```text
Pseeding = 1600 - (R - 1) * 4
```

其中 `R` 是旧排名位置。

例子:

- 第 1 名: 1600
- 第 3 名: 1592
- 第 100 名: 1204
- 第 200 名: 804

## 与旧规则相比的改进

新版算法去掉或缓解了旧规则中的几个问题:

- 不再使用年度平均积分，减少时间衰减和每日波动问题。
- 减少球队通过少踢友谊赛影响排名的空间。
- 去除洲际权重，让不同大洲球队理论上有更平等的上升机会。
- 友谊赛权重降低，正式比赛权重提高。
- 世界杯和洲际大赛淘汰赛权重更高。
- 东道主即使少踢预选赛，也不会像旧规则下那样严重受损。

## 对 FYP 的启发

如果项目中使用 FIFA Ranking，应该说明它本身已包含:

- 历史比赛结果
- 对手强弱
- 比赛重要性
- 赛前预期与实际结果之间的差异

因此 FIFA Ranking 不只是名次变量，而是一个动态强度评分。建模时可以使用:

- 两队 FIFA points 差
- 两队 FIFA rank 差
- FIFA expected result `We`
- 比赛重要性 `I`

如果做世界杯预测，`We` 公式尤其有用，因为它能直接转化为类似 Elo 的胜率特征。
