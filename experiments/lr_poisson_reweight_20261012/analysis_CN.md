## 2. 方法与可检验的数学性质

类别顺序为 `[客胜, 平局, 主胜]`。对任意比分 `(i,j)`，泊松比分概率为 `P_ij`；LR 输出 `q_c`，泊松在类别 `c` 内的总概率为 `S_c`，则融合值为 `F_ij = q_c * P_ij / S_c`。

- `sum_{(i,j) in c} F_ij = q_c`，总概率恰为 1，组内 `F_ij/F_kl = P_ij/P_kl`。
- 无需假设从三个类别概率唯一恢复泊松 `λ_home` 与 `λ_away`，也不能只保留 LR 预测的最大类别。
- 对真实比分 `(i,j)` 和真实类别 `y`：`NLL_fusion(i,j) - NLL_poisson(i,j) = -ln(q_y) + ln(S_y)`。因此在相同测试集上，**真实比分平均 NLL 差值等于 LR 减泊松的胜平负 Log Loss 差值**。这一恒等式作为运行时的严格数值审计。
- 其他比分指标不受以上恒等式保证：模式（最高概率）比分可能跳变，主客队期望进球数也会改变。进球 MAE 与 ±1 球比率都必须由**完整比分分布的期望值**计算，众数比分命中率独立报告。

## 3. 已有证据与不可直接下结论的项目
